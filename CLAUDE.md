# Pandemic

Cooperative Pandemic board game: Python rules engine, RL environments, FastAPI WebSocket server,
React frontend, deployed to an Oracle Cloud VM.

- **Deployment work in progress:** read `docs/DEPLOY_STATUS.md` first (status, exact remaining
  steps, troubleshooting). Human guide: `docs/DEPLOY.md`.
- Engine API: `docs/ENGINE_API.md`. Server protocol: `docs/SERVER_PROTOCOL.md`. Frontend:
  `web/README.md`.

## Layout

- `src/pandemic/engine/`: rules engine (`new_game`, `legal_actions`, `step`, `observe`).
- `src/pandemic/ai/`: PettingZoo/Gymnasium envs, action encoding, baseline agents.
- `src/pandemic/server/`: FastAPI app (`app.py`), rooms (`rooms.py`), debug client at `/debug`.
- `web/`: Vite + React + TS client; `web/src/data/mapPaths.ts` is generated by `npm run gen:map`.
- `deploy/`: docker-compose + Caddyfile copied to the VM; `.github/workflows/deploy.yml`: CI/CD.

## Commands

- Python tests and lint: `uv run --all-extras pytest -q`, `uv run ruff check`
- Frontend: `cd web && npm ci && npm test && npm run build`
- Local server: `uv run --all-extras python -m pandemic.server --port 8000` (serves `web/dist`)
- Docker image: `docker build -t pandemic:local .`

## Notes

- `Pandemic_Rules.md` (rulebook summary) is local-only and gitignored; the repo is public.
- Pushes to `main` run tests, build a multi-arch image to ghcr.io, and deploy when the repo
  variable `DEPLOY_ENABLED=true`.
