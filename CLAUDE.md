# Pandemic

Cooperative Pandemic board game (unofficial fan project, MIT): Python rules engine, RL
environments, a multiplayer server with two protocol-identical backends (FastAPI, and a
Cloudflare Worker with Durable Objects), and a React frontend.

- **Deployment state:** `docs/DEPLOY_STATUS.md` (short). Overview and CI: `docs/DEPLOY.md`;
  targets: `docs/CLOUDFLARE.md`, `docs/DEPLOY_ORACLE.md`.
- Engine API: `docs/ENGINE_API.md`. Server protocol: `docs/SERVER_PROTOCOL.md`. Frontend: `web/README.md`.

## Layout

- `src/pandemic/engine/`: rules engine (`new_game`, `legal_actions`, `step`, `observe`).
  `event_cards.py` = event cards; `game_events.py` = events emitted by `step`.
- `src/pandemic/ai/`: PettingZoo/Gymnasium envs, action encoding, baseline agents.
- `src/pandemic/server/`: `rooms.py` (transport-agnostic rooms, limits, create-request parsing,
  eviction; shared by both backends), `meta.py`, `app.py` (FastAPI).
- `cloudflare/worker/`: Worker (`src/entry.py`) + `RoomDO`. `scripts/sync.sh` copies `engine/`,
  `data/`, `server/{__init__,rooms,meta}.py` and `web/dist` in (gitignored copies; never commit them).
- `web/`: Vite + React + TS client; `web/src/data/mapPaths.ts` is generated by `npm run gen:map`.
- `deploy/`: docker-compose + Caddyfile for the VM; `.github/workflows/ci.yml`: CI/CD.
- `tests/`: pytest; `tests/conformance/` is the protocol-parity suite (not collected by pytest).

## Commands

- Python: `uv run --all-extras pytest -q`, `uv run ruff check`, `uv run mypy src` (Python 3.12).
- Frontend (Node 22): `cd web && npm ci && npm test && npm run build`
- Local server: `uv run --all-extras python -m pandemic.server --port 8000` (serves `web/dist`)
- Conformance: `uv run --all-extras python tests/conformance/run.py fastapi|worker` (worker needs
  uv >= 0.13.4 and a built `web/dist`).
- Docker image: `docker build -t pandemic:local .`

## Rules for changes

- Anything in `rooms.py` or the engine affects both backends: run the conformance suite for both,
  and keep `app.py` and `cloudflare/worker/src/entry.py` behaving identically (the Worker needs a
  manual redeploy; see `docs/CLOUDFLARE.md`).
- The engine and `rooms.py` must stay Pyodide-compatible (Python 3.12, stdlib only).

## Notes

- `Pandemic_Rules.md` (rulebook summary) is local-only and gitignored; the repo is public.
- Pushes to `main` run CI, build a multi-arch image to ghcr.io, and deploy only when the repo
  variables `DEPLOY_ENABLED` / `CLOUDFLARE_ENABLED` are `true`.
- `rooms/` (saved FastAPI rooms) and `.playwright-mcp/` are local dev state.
